# نظام البحث عن قطع الغيار بالصورة

موقع فيه تسجيل دخول/حساب، وصفحة رئيسية بيها زر "ادخل صورة" — ترفع صورة القطعة
ويطلعلك أقرب القطع المشابهة من مخزنكم مع الكود، الاسم، الكمية، والرف.

## ليش ما اشتغل هذا مباشرة بالمحادثة؟

بنيت البيانات كاملة من ملف الإكسل اللي دزيته (٢٠,٥٤٧ قطعة، ٩٩.٦٪ منهم عندهم
رابط صورة حقيقي مخزون على سيرفر Service Soft). بس أني أشتغل بمكان معزول عن
النت، فما أقدر أنزل هالصور من هنا لأبني قاعدة المطابقة. لازم تشغّل خطوة واحدة
(`build_index.py`) على جهاز أو سيرفر عندكم فيه اتصال بالنت، ومرة وحدة بس.

## خطوات التشغيل

### 1. تنصيب المتطلبات
```bash
pip install -r requirements.txt
```
(يفضّل تسويها بـ virtual environment)

### 2. حط ملف الإكسل بمجلد data
أذا الملف مو موجود أصلاً، حطه بالمسار: `data/StorageList.xlsx`

### 3. ابني قاعدة الصور (خطوة تسوى مرة وحدة، تحتاج نت)
```bash
python build_index.py --excel data/StorageList.xlsx --out data/index
```
- هذا يحمّل كل صورة من الروابط، ويحول كل وحدة إلى "بصمة" رقمية (embedding)
  باستخدام موديل CLIP، ويخزنها بمجلد `data/index/`.
- تقريباً ٢٠ ألف صورة، فراح ياخذ وكت (من نص ساعة لكم ساعة حسب سرعة النت
  وقوة الجهاز). يحفظ التقدم كل ٥٠ قطعة، فإذا انقطع تگدر تشغله مرة ثانية
  ويكمل من وين وقف.
- للتجربة السريعة على عدد محدود أول: أضف `--limit 200`

### 4. شغّل الموقع
```bash
python app.py
```
افتح المتصفح على: `http://localhost:5000`
سوي حساب من صفحة "إنشاء حساب"، وبعدين سجل دخول وابدي تستخدمه.

## عشان الموقع يوصله كل الفروع (مو بس جهازك)

هذا التشغيل (`python app.py`) للتجربة على جهازك بس. للنشر الحقيقي:
- ترفع المشروع على سيرفر (VPS) — مثل DigitalOcean, Hetzner, أو أي مزود عراقي/خليجي
- تشغله بـ `gunicorn` بدل `python app.py`، مع `nginx` قدامه
- تربطه بدومين (مثل `parts.yourcompany.com`) وشهادة SSL (مجانية عبر Let's Encrypt)

إذا تريد، أگدر أساعدك بخطوات النشر بالتفصيل لما توصل لهذي المرحلة — قلي بس
وين ناوي تستضيف السيرفر (جهاز عندكم؟ VPS؟) ونكمل.

## تحديث قاعدة البيانات لاحقاً

كل مرة يضاف صنف جديد أو تتغير بيانات المخزن، صدّر إكسل جديد من Service Soft
وشغّل نفس أمر `build_index.py` عليه — القطع الجديدة بس اللي راح تنضاف
(القديمة تنحفظ تلقائياً).

## ملاحظة عن الدقة

المطابقة تعتمد على تشابه الشكل العام للقطعة (اللون، الشكل، الملمس بالصورة).
قطع متشابهة كثير بالشكل (مثل براغي أو فلاتر بمقاسات مختلفة) ممكن تجي مع
بعض بالنتائج — لهذا النظام يعرض أفضل ٥ نتائج مو نتيجة وحدة بس، وين الموظف
يختار الصح من بينهم.
